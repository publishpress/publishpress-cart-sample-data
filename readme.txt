Create removable sample data for PublishPress Cart development and QA sites.

== Description ==

Install alongside PublishPress Cart or PublishPress Cart Pro. Open PublishPress Cart > Sample Data and click Generate Sample Data. This creates six products, 180 orders dated across the previous year, 36 subscriptions, categories, and tags. Pro also receives a global coupon and catalog records for a collection, post-checkout offer, and subscription upgrade path. The bundled `sample-data/sample_ppcart_tax_rates.csv` is a reference file for manual import; this release does not import tax rates or create affiliate records. Pro catalog records are demonstration placeholders, not fully configured checkout flows. Use Remove Sample Data to delete tagged records.
